# Install VR Tools for 3ds Max

[![Download VR Tools Installer](https://github.com/vinayragbotra/VR_tools/raw/refs/heads/main/download.svg)](https://raw.githubusercontent.com/vinayragbotra/VR_tools/main/feed/VR_Tools_Installer.mzp)

1. Download **VR_Tools_Installer.mzp** using the blue button above.
2. In 3ds Max, choose **Scripting > Run Script** and select the downloaded file.
3. Follow the installer dialog, then restart Max. Open **VR_tools > VR Tools**.

Use **Discover** for the main scripts and **Other scripts** for optional tools. Select **Install** on any card. Open **Installed** to run or uninstall a script. Uninstalled scripts can be installed again.

For updates, choose **Check updates** in the panel. Use **Update manager** for the panel itself and restart Max afterward.

**Already installed from the old server?** Run this GitHub installer once to switch this PC to GitHub and keep its installed scripts. You can also enter the [GitHub feed](https://raw.githubusercontent.com/vinayragbotra/VR_tools/main/feed/catalog.json) in **Feed settings** using the address below.

```text
https://raw.githubusercontent.com/vinayragbotra/VR_tools/main/feed
```

3ds Max 2024–2026 on Windows. A GitHub account, Git, and ChatGPT are optional. Max 2024 legacy menus refresh after a restart.
